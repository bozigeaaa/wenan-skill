# Script Pattern

## Default Structure

1. Hotspot hook.
   - State the verified event carefully.
2. Correct the easy misunderstanding.
   - Explain what should not be exaggerated.
3. One industry impact point.
   - Choose one operational pathway only.
4. Saudi project scene.
   - Translate the impact into project manager/procurement/camp manager language.
5. Practical takeaway.
   - Tell the viewer what to recheck.
6. Natural ending.
   - Ask a question or preview the next related point.

## Spoken Lines

- "这个新闻，不建议拿来吓人。"
- "真正该看的，不是新闻标题，而是它会不会改变项目假设。"
- "对在沙特干工程的人来说，最先要重算的是..."
- "这不是政治分析，这是项目交付里的风险链条。"
- "别把可能性写成已经发生，但也别假装它和项目没关系。"

## Strait Of Hormuz Example

User claim:

```text
中东政治局势影响到霍尔木兹海峡停关，货船运输重新绕行入关。
```

Safer analysis:

```text
Do not assume "停关" unless verified. First check whether the Strait was fully closed, partially restricted, under temporary navigation management, or only facing increased security risk. If shipping is not fully closed, write "通行风险上升" or "船期和保险开始被重新评估".
```

Possible one-point title:

```text
霍尔木兹一紧张，沙特工地最先该重算什么？
```

Single point:

```text
Delivery-time assumptions for imported materials and camp equipment become less reliable.
```

Do not cover in the same script:

- Energy price.
- Freight price.
- War-risk insurance.
- Port congestion.
- Local stock.
- Product solution.

Those can become separate episodes.

## Routing

After choosing the one point:

- If the script is broad attention/industry observation, use `$saudi-breakout-story-script`.
- If it explains a mechanism or policy boundary, use `$saudi-professional-knowledge-script`.
- If the user explicitly wants product connection, use `$saudi-product-seeding-script` or the relevant product skill.
- If the draft feels too written, use `$script-oralization-rewriter` after the script is complete.
