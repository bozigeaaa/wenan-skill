# Brand Proof Pattern

## Default Structure

1. Start with a trust problem in Saudi projects.
2. Explain why this problem appears: distance, language, customs, installation, responsibility split, or after-sales handoff.
3. Introduce one verified company capability.
4. Explain how that capability reduces a specific project risk.
5. End with a buyer self-check.

## Good Angles

- "本地工厂" is valuable because it reduces cross-border uncertainty, not because it sounds impressive.
- "中文团队" is valuable when design, procurement, finance, and site communication need one clear chain.
- "全流程团队" is valuable because handoff gaps create delays and responsibility ambiguity.
- "本地库存" is valuable only when the product and stock status are verified; otherwise use cautious wording.

## Opening Patterns

- "很多中资项目在沙特吃亏，不是产品不会买，而是交付链条太长。"
- "选供应商，别只看报价单，也要看出问题时谁负责到底。"
- "在沙特做营地，真正麻烦的不是买一批房子，而是把设计、运输、安装和售后串起来。"

## Ending Patterns

- "所以选供应商时，别只问有没有产品，也要问交付链条谁来兜底。"
- "你们现在合作的供应商，是只卖货，还是能把现场交付一起管起来？"
- "品牌背书不是一句口号，最后都要落到项目现场的响应速度上。"

## Avoid

- Empty claims: "实力雄厚", "品质卓越", "值得信赖".
- Unsupported ranking: "行业领先", "沙特第一".
- Fake customer praise or unnamed project cases.
