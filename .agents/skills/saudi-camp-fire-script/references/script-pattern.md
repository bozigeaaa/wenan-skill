# Script Pattern

Use this four-part compliance pattern for Saudi camp fire-safety scripts. It is adapted from the accepted draft, with fact-check guardrails added.

## Four-Part Structure

### 1. Manufacture The Crisis, Break The False Comfort

Goal: make the viewer realize the dangerous misconception is not "no fire-rated material", but "assuming material name equals compliance".

Use:
- A sharp title that challenges the wrong focus.
- An opening that acknowledges professional reality: formal projects generally know fire-rated materials matter.
- The core question: "不要问有没有材料，要问这套配置能不能对应 SBC 801 / Civil Defense 的具体要求。"

Good title directions:
- "防火材料大家都有，关键是能不能对应 SBC 801"
- "去沙特建营地，先看懂 SBC 801 这条硬要求"
- "Civil Defense 卡的不是材料名，是规范对接能力"

Avoid:
- Making professionals look stupid.
- Pretending today's regular projects mainly use obviously outdated unsafe materials unless sourced.

### 2. Pure Objective Code Education

Goal: act like an industry judge. Do not mention Eastern Camel or product names in this section.

Pick only 1-2 concrete rules. For each rule:
- Name the rule direction: risk zoning, fire separation, firestopping, egress, alarm/firefighting systems, document/site consistency.
- Explain the rule in plain Chinese.
- Translate it into camp scenes: dormitory, office, kitchen/canteen, warehouse, equipment room.
- Use professional terms when useful: 风险分区, 耐火极限, 防火分隔, 节点封堵, 穿墙孔洞, 材料性能报告, BOQ, fire protection, life safety.

Do not write vague lines like "SBC 801 is strict". Say what it checks.

### 3. Optional Capability Landing: Only If It Answers The Point

Goal: keep pure compliance education product-free unless Eastern Camel capability directly answers the requirement.

Before writing this section, apply the product/company landing gate:

- Did the user explicitly ask to connect the topic to Eastern Camel, a product, delivery, or factory capability?
- Is the topic about product selection, supplier selection, delivery capability, material configuration, or brand proof?
- Does the company/product fact directly answer this video's one fire-safety question?

If the answer is no, skip brand/product language and use a project self-check, next-topic teaser, or comment prompt instead.

Do not mention local factory, factory area, or `15000㎡` unless the point is local manufacturing scale, production capacity, or delivery certainty. Factory area is not a generic trust line for fire-safety education.

First, identify the ordinary low-price risk only if it is defensible:
- "低价方案容易只讲材料名，不讲完整构造和证据链。"
- "容易忽略板缝、穿线孔、BOQ 和现场安装的一致性。"
- "一套模板套宿舍、食堂、仓库，容易在用途风险上说不清。"

Avoid unsupported accusations:
- "很多厂家偷工减料"
- "根本不防火"
- "撑不过15分钟"
- "大批项目被拆除"

If the gate passes, land Eastern Camel through rule-by-rule mapping:
- Risk zoning -> front-end planning and physical separation of kitchen, dormitory, office, warehouse.
- Fire separation -> wall/roof/door configuration matched to project requirements.
- Firestopping -> seam, joint, cable penetration, pipe penetration treatment when confirmed.
- Evidence chain -> drawings, BOQ, material reports, site installation, and inspection consistency.

Use hard parameters only when confirmed. If confirmed, make them concrete; if not, leave them out or flag them.

### 4. Flexible Closing And Series Continuity

Goal: build expert persona, invite interaction, and create future episode continuity without repeating one fixed slogan.

Choose one closing style based on the script:

1. **Next-topic teaser**: use when the topic naturally opens a harder compliance problem.
- "消防水和报警系统怎么跨场景联动？"
- "疏散通道净宽怎么留才不容易违规？"
- "现场材料喷码、测试报告、BOQ 清单怎么前后一致？"

2. **Comment interaction**: use when viewers can compare their project situation.
- "你们营地现在最容易被卡的是分隔、疏散，还是消防系统？评论区说一个，我按真实场景拆。"
- "如果你正在做沙特营地，把你最担心的消防点留在评论区，下一期我挑一个讲透。"

3. **Topic request**: use when building a content series.
- "下一期想听 Civil Defense 查图纸、查材料，还是查现场？你们点题，我来拆。"
- "沙特营地消防还有很多细节，你们想先听报警系统，还是疏散通道？"

4. **Project self-check question**: use when the episode is pure professional education.
- "你可以先回去看一眼，你们图纸、BOQ 和现场做法是不是能对上。对不上，问题通常就从这里开始。"
- "别急着问材料名，先问这套配置能不能把用途、风险和现场证据链说清楚。"

5. **Light brand close**: use sparingly when the script has clearly landed Eastern Camel's capability and the landing gate passes.
- "东方骆驼做沙特营地，真正想解决的不是一句防火材料，而是把消防逻辑从图纸落到现场。"
- "出海建营地，别只听材料名。把规范逻辑讲清楚，项目才稳。"

Avoid using the same closing sentence repeatedly. Do not force the old fixed line:
- "关注东方骆驼，出海建营地，我们陪你把消防逻辑讲清楚。"

## Language Style

- Use short spoken sentences.
- Keep terms like SBC 801, Civil Defense, fire protection, life safety when useful, but explain them immediately.
- Prefer direct phrases:
  - "不是看材料名字。"
  - "它看的是用途、风险、分隔和现场能不能对上。"
  - "这才是民防局现场检查容易卡人的地方。"
- Avoid long academic paragraphs.
- Professional, cold, crisp, and consultant-like; avoid cheerful sales tone.

## Bad Pattern To Avoid

Do not structure the script as:

1. "What is fire logic?"
2. "What is SBC 801?"
3. "What products do we have?"

This easily becomes two or three topics. Instead, choose one requirement and make every paragraph serve that requirement.
