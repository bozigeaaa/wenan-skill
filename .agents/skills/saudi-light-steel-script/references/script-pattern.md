# Light Steel Script Pattern

Use this pattern for Saudi thin-walled light steel house scripts. The final script should not show these labels unless the user asks for structure.

## Shape

### 1. Challenge One Wrong Focus

Open by correcting a realistic but incomplete decision habit.

Good directions:
- "很多人看轻钢房，第一反应是问墙厚多少。"
- "长期营地选房子，不能只看搭得快。"
- "在沙特，轻钢房真正要扛的不是一个参数，是整套现场条件。"
- "同样叫轻钢房，差距往往不在名字，而在围护系统。"

Avoid:
- Making buyers look naive.
- Saying the market is full of fraud without evidence.
- Starting with a list of product specs.
- Starting with one parameter and ending with a different topic.

### 2. Explain One Mechanism

Explain the selected mechanism in plain Chinese. Pick one, not all:

- Structural logic: cold-formed thin-walled C steel, load path, light weight, prefabrication.
- Envelope logic: wall board + glass wool + reflective layer + inner/outer boards.
- Climate logic: heat, sand, corrosion, AC load, and maintenance.
- Usage logic: medium/long-term camp, office, dormitory, image project.
- Delivery logic: local factory, local stock, Chinese coordination, installation support.

Do not mix these in one script. For example:

- G550/C-shaped steel -> steel grade, yield strength, section logic, why thickness alone is incomplete.
- Heat/sand/corrosion -> envelope, sealing, anti-corrosion, maintenance boundary.
- Local delivery -> local manufacturing, project资料包, installation coordination.
- SBC 308/309 -> design/construction compliance boundary.

If the title is one of these, the ending must return to that exact mechanism.

Every technical term needs a plain explanation:
- "围护系统，就是外墙、屋面、门窗这几层一起决定室内环境。"
- "玻璃棉不是拿来讲参数好看的，它解决的是热量、声音和防火方向的基础性能。"
- "轻钢龙骨不是只看钢材名字，要看它怎么和墙板、屋面、地面连成一个体系。"

### 3. Put It Into A Saudi Project Scene

Translate the mechanism into a real Saudi site concern:

- High temperature and AC load.
- Sand and window/door sealing.
- Long-term living comfort.
- Office/dormitory image and management.
- Maintenance during project operation.
- Project city and environmental boundary.

Use grounded lines:
- "利雅得夏天，空调不是舒适配置，是运营成本。"
- "风沙季过后，真正麻烦的是细沙从门窗缝、接缝和设备间一路进来。"
- "短期周转看速度，中长期驻地要看后面半年、一年会不会持续返修。"

### 4. Land Eastern Camel Only When It Answers The Point

Do not force brand insertion. If relevant, map one capability to the mechanism:

- Wall system -> glass wool, cement fiber board/calcium silicate board, inner/outer boards, PVC windows, steel doors.
- Structural system -> thin-walled steel framing and prefabricated assembly, when confirmed.
- Long-term camp -> more suitable for office, dormitory, and image-demanding projects.
- Saudi delivery -> local factory, local stock, local delivery, installation coordination.

Good landing:
- "所以这类项目，不能只问有没有轻钢。要问墙体、屋面、门窗和现场安装是不是一套系统。东方骆驼做薄壁轻钢，重点就在这里。"
- "如果你的项目是中长期驻地，真正要算的是后期空调、维护和返工成本，不是只看第一口报价。"

Avoid:
- "我们产品最好."
- "只有我们能做."
- "用了就一定没问题."

### 5. Flexible Ending

Choose one ending style:

- Comment prompt: "你们在沙特项目上，轻钢房最担心的是隔热、风沙，还是后期维护？评论区说一个，我按现场逻辑拆。"
- Topic request: "下一期你们想听墙体系统、屋面系统，还是轻钢和打包箱怎么选？"
- Self-check: "你可以先问供应商一句：这个参数到底解决的是结构、隔热，还是交付？答不清，后面就容易乱。"
- Light brand close: "出海做中长期营地，房子不是搭起来就结束。真正考验，是住进去以后还稳不稳。"

When using local-supplier perspective, prefer:
- "在沙特做中长期营地，房子不是搭起来就结束。真正考验，是住进去以后还稳不稳。"

Avoid repeating one fixed CTA.
