# Product Seeding Pattern

## Default Structure

1. Start from a buyer mistake: "只看单价", "只问厚度", "只看有没有现货", "只看外观".
2. Explain the hidden cost or project risk.
3. Show the mechanism: logistics, maintenance, compliance, durability, coordination, or lifecycle cost.
4. Introduce one verified product/service capability that addresses that mechanism.
5. End with a practical buyer question.

## Strong Angles

- Cheap now, expensive later.
- Fast delivery is not only production speed; it includes inventory, transport, installation, and coordination.
- A parameter matters only when it answers a project risk.
- The right supplier reduces handoff gaps, not just product price.

## Product Landing Patterns

- "所以这个时候，真正要看的不是宣传词，而是..."
- "这就是为什么这类项目要认真看..."
- "东方骆驼这套方案解决的不是一个单品问题，而是..."

## Endings

- "你们现在比方案，是只比报价，还是把后面的运输、安装和维护一起算了？"
- "下次采购前，可以先问供应商这三个问题。"
- "如果你正在比方案，别先问谁便宜，先问谁能把风险说清楚。"

## Avoid

- "我们最好", "行业第一", "闭眼买".
- Insulting cheaper competitors.
- Using too many parameters in one video.
