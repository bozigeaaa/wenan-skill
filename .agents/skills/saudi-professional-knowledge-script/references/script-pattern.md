# Professional Knowledge Script Pattern

## Default Structure

1. Name the common misunderstanding.
2. Define the actual boundary or mechanism.
3. Explain why it matters in Saudi projects.
4. Give a practical check method.
5. End with a self-check or next-topic teaser.

## Opening Patterns

- "很多人把这个问题想简单了。"
- "在沙特做项目，这件事不能只按国内经验判断。"
- "这个词很多人听过，但真正影响项目的不是名字，而是边界。"
- "今天不讲产品，讲一个项目上经常被误解的规则。"

## Practical Ending Patterns

- "所以别急着问能不能做，先问适不适用于你的项目类型。"
- "下次听到这个说法，先问一句：适用范围是什么？"
- "这类问题不是靠一句经验判断，要看业主、用途、图纸和审批路径。"

## Avoid

- Starting as科普 but ending as hidden sales pitch.
- Turning a conditional rule into a universal rule.
- Using a regulation name without explaining what it actually controls.
