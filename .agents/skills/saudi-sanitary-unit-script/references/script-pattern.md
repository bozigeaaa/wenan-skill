# Sanitary Unit Script Pattern

Use this pattern for Saudi TBOX / K-series mobile toilet, shower room, and modular sanitary-unit scripts. The final script should not show these labels unless the user asks for structure.

## Shape

### 1. Point Out One Real But Delayed Problem

Start with a problem project teams often postpone or underestimate.

Good directions:
- "很多营地做预算，卫生间永远排在最后。"
- "移动厕所真正麻烦的，往往不是买的时候，而是用了一段时间以后。"
- "在沙特工地，厕所这件事没人想第一个提，但出问题时第一个挨批的通常是项目经理。"
- "别只问一套厕所多少钱，先问它后面好不好维护。"

Avoid:
- Crude or disgusting imagery.
- Writing workers as unrealistic collective protesters.
- Starting with a full model list.

### 2. Explain One Mechanism

Explain one sanitary mechanism in plain Chinese. Pick one, not all:

- Odor mechanism: ventilation, sealing, drainage, sewage interface, cleaning frequency, usage intensity.
- Model selection: squat/sit/shower/single/dual/combined units matched to camp population and scene.
- Maintenance logic: floor material, corrosion, water use, cleaning access, replacement parts.
- Deployment logic: packing dimensions, container loading, on-site assembly, emergency replenishment.
- Compliance/management logic: camp inspection, client check, rectification pressure, daily operation.

Every technical term needs a plain explanation:
- "排污接口，就是污水从设备进管道的那个连接点。这里密封不好，后面就容易返味。"
- "打包尺寸不是纸面参数，它决定一车能拉多少、现场能不能快速补位。"
- "304 不锈钢地面不是为了好看，核心是耐腐蚀、好清洁、减少后期维护压力。"

### 3. Put It Into A Saudi Project Scene

Translate the mechanism into a Saudi site concern:

- Remote camp and urgent deployment.
- High temperature and odor amplification.
- Cleaning and maintenance management.
- Client inspection or owner walk-through.
- Labor camp support facilities.
- Factory/workshop temporary sanitary use.
- Outdoor site exposure, heat, sand, and corrosion.

Use grounded lines:
- "沙特高温下，味道会被放大，维护频率也会被放大。"
- "甲方来查营地，卫生间不是主工程，但它最容易被一眼看到。"
- "临时营地最怕的不是没有厕所，而是有了以后天天返修、天天投诉。"

### 4. Land TBOX / K-Series Only When It Answers The Point

Do not force product insertion. If relevant, map one capability to the mechanism:

- Odor/drainage -> ventilation, sealing, drainage interface, cleaning access when confirmed.
- Maintenance -> 304 stainless steel floor, anti-corrosion/anti-rust, easy cleaning when confirmed.
- Deployment -> packing size, container loading, modular assembly, local stock when confirmed.
- Scenario selection -> KS-S1, KS-S2, KS-W1, KS-W2, shower units, combined units when confirmed.
- Saudi delivery -> local stock, local installation, Chinese coordination, after-sales response.

Good landing:
- "所以这类产品，不能只看外观。要看排污、通风、地面材料和后期维护是不是一起考虑。"
- "如果是临时营地急用，真正要算的是能不能快速补位、能不能减少后期管理麻烦。"

Avoid:
- "我们产品最好."
- "用了就一定没味道."
- "肯定过检查."

### 5. Flexible Ending

Choose one ending style:

- Comment prompt: "你们营地卫生间最头疼的是异味、清洁，还是后期维修？评论区说一个，我按现场逻辑拆。"
- Topic request: "下一期你们想听 K 系列型号怎么选，还是移动厕所为什么会返味？"
- Self-check: "你可以先看一眼，你们现在的厕所，是只解决了有无，还是把排污、通风和维护都考虑进去了。"
- Maintenance ending: "你可以先看一眼，你们现在的厕所，后期维护到底好不好做。"
- Light brand close: "营地配套不是小事。真正稳定的项目，连卫生间这种细节都不能靠凑合。"

Avoid repeating one fixed CTA.
