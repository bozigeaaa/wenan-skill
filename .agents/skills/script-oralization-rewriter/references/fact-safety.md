# Fact Safety

## Locked Facts

When oralizing, treat these as locked unless the user asks for a fact revision:

- Numbers: dimensions, density, loading quantity, price, time, capacity, temperature, fire duration.
- Names: SBC 801, Civil Defense, Salamah, ASTM, UL, SASO/SABER, model names.
- Product parameters: material, thickness, component configuration, package size, container loading.
- Market claims: "mainstream", "competitors", "local supplier", "current market".
- Consequences: stop work, rectification, inspection failure, fines, client rejection.

Do not change, intensify, or add these facts during口语化.

## Unsafe Amplification

Avoid these transformations:

| Source Says | Do Not Rewrite As | Why |
|---|---|---|
| "有助于降低风险" | "一定能通过检查" | Turns support into guarantee |
| "需要核实规范要求" | "规范白纸黑字写死了" | Invents certainty |
| "可能增加运输成本" | "运费比设备还贵" | Adds unverified cost ratio |
| "普通方案维护压力大" | "市面上很多厂家偷工减料" | Accuses competitors |
| "材料具备耐火性能" | "1000°C 下顶住一小时" | Adds test condition/result |

## Safe口语化

Use phrasing that keeps uncertainty honest:

- "如果这个参数没算清楚，后面成本很容易失控。"
- "具体要看项目图纸和配置，不能一句话包过。"
- "它解决的不是面子问题，而是运输、维护和交付问题。"
- "这个说法不能只听供应商拍胸脯，要看报告、图纸和清单能不能对上。"

## If The Source Draft Is Too Risky

When the draft contains unsupported high-risk facts:

1. Do not dramatize the risky line.
2. Downgrade to a safer professional expression.
3. If the user asked for visible review, list the risky facts separately.
4. If the user only asked for a rewritten script, output a safer script without exposing the internal self-check.
