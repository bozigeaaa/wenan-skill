# Oralization Patterns

## Rewrite Moves

Use these moves selectively. Do not stack all of them in every paragraph.

| Written Draft Problem | Oralized Move | Example |
|---|---|---|
| Starts too flat | Start with a direct warning or question | "买移动卫生间，别一上来只问单价。" |
| Long abstract sentence | Split into spoken beats | "账面上省了。可一发货，问题来了。" |
| Concept feels technical | Name it, then explain in plain words | "装柜效率，说白了，就是一柜到底能装多少套。" |
| Product entry feels hard | Use "所以这时候..." bridge | "所以这时候，扁平化打包就不是卖点词了，是成本问题。" |
| Ending is generic | Leave a self-check or comment prompt | "你们现在算成本，是只算设备价，还是连运输一起算？" |

## Useful Spoken Connectors

Use sparingly:

- "说白了，..."
- "你想啊，..."
- "问题就在这。"
- "很多人会忽略一点。"
- "这时候差距就出来了。"
- "听起来像小事，到了现场就不是小事。"
- "别小看这个参数。"
- "真正影响成本的，往往不是你第一眼看到的价格。"

## Rhythm Rules

- Keep most sentences under 25 Chinese characters when possible.
- Use one-line pauses for important turns.
- Put numbers in short sentences so口播不打结.
- Avoid three or more technical clauses in one sentence.
- Use rhetorical questions to open or pivot, not every paragraph.

## Intensity Ladder

Choose an intensity that matches evidence:

1. Mild: "很多人会忽略"
2. Clear: "这会直接影响后期成本"
3. Sharp: "这不是省钱，是把成本挪到后面"
4. High-risk, use only with evidence: "会导致整改/停工/验收失败"

Default to level 2 or 3 for B2B product scripts. Do not use level 4 unless the source draft already has verified support.

## Before And After Example

Before:

```text
项目采购，算账不能只算设备出厂价。物流和安装成本，才是真正影响落地总成本的隐形因素。
```

After:

```text
所以采购算账，别只盯着出厂价。

设备便宜，不一定真的便宜。

海运、陆运、装卸、安装，这些加起来，才是项目最后要付的钱。
```
