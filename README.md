# 东方骆驼短视频脚本文案知识库

这是东方骆驼 / 深圳钧瀚科技用于 B2B 短视频脚本文案生成的 Codex 项目。

项目的核心目标不是堆提示词，而是把公司资料、沙特临建行业认知、产品参数、内容规则和已验证过的写法沉淀到同一个工作目录里，让 Codex 在生成脚本文案前先做资料判断和事实核实，尽量减少参数乱用、硬广腔、假现场感和不可靠表达。

## 当前定位

本项目服务于以下内容方向：

- 沙特临建、工程营地、移动房屋、模块化建筑相关短视频脚本
- 东方骆驼 / EASTERN CAMEL 品牌背书内容
- 薄壁轻钢房屋、打包箱、拼装房屋等产品内容
- TBOX / K 系列移动厕所、移动卫浴、模块化卫生间内容
- SBC、Civil Defense、Salamah、SABER/SASO 等沙特行业合规科普
- 国际热点对沙特工程、营地、临建行业影响的脚本选题

默认输出目标是中文口播脚本，面向项目经理、采购负责人、营地管理者、EPC/总包、在沙特做工程的人群。

## 关键文件说明

`AGENTS.md`  
项目总规则。这里定义了脚本文案的工作流、内容类型判断、事实核实要求、输出格式、调门红线和资料出处规则。Codex 处理本项目任务时应优先遵循它。

`knowledge/`  
公司资料知识库。里面包含产品介绍、公司介绍、沙特行业认知、参数表、PDF 画册、Excel 表格和从文档中抽取出的文本。涉及参数、规格、认证、法规、交付能力等事实时，应回到这里的原始资料核实。

`knowledge/AI资料导航索引.md`  
知识库导航入口。开始写脚本前，先读它，用来判断应该读取哪些资料文件。它不是最终事实源，不能替代原始 Excel、PDF、DOCX、TXT。

`.agents/skills/`  
本项目自定义脚本技能。不同内容方向有不同 skill，用来约束口播脚本的结构、语气、事实边界和禁止表达。

辅助脚本  
根目录下的 `dump_excels.py`、`extract_docx.py` 等用于把 Excel、DOCX 等资料转成更容易检索的文本，方便 Codex 快速定位事实来源。

## 已有 Skills

当前项目内包含这些脚本文案技能：

- `global-hotspot-industry-impact-script`：国际热点对沙特临建/工程/营地行业的影响脚本
- `saudi-brand-proof-script`：沙特本地工厂、本地库存、本地交付等品牌背书脚本
- `saudi-breakout-story-script`：沙特生活、行业见闻、破圈故事类脚本
- `saudi-camp-fire-script`：SBC 801、Civil Defense、营地消防合规脚本
- `saudi-light-steel-script`：薄壁轻钢房屋、G550、围护系统、选型对比脚本
- `saudi-product-seeding-script`：产品种草和销售转化脚本
- `saudi-professional-knowledge-script`：沙特临建行业专业科普脚本
- `saudi-sanitary-unit-script`：TBOX / K 系列移动厕所、移动卫浴、卫生间脚本
- `script-oralization-rewriter`：已有脚本的口语化改写

## 推荐使用流程

1. 用户给出一个话题或初稿。
2. Codex 先读取 `AGENTS.md` 和 `knowledge/AI资料导航索引.md`。
3. 根据话题选择对应 skill。
4. 只读取本次任务相关的资料，不一次性读取全部资料。
5. 涉及参数、规格、法规、认证、产能、安装时长、交付能力等事实时，回到原始资料核实。
6. 若涉及当前国际时讯、竞品现状、市场主流方案或政策更新，必须联网核实。
7. 生成脚本时只讲一个核心问题，避免一个稿子里同时讲厚度、运输、抗风、规范、量产等多个点。
8. 默认只输出完整脚本文案；如果正文使用了事实依据，底部必须附 `资料出处`。

## 脚本输出原则

- 一条视频只讲一个核心问题。
- 标题、开场、正文参数、产品落点和结尾必须回答同一个问题。
- 默认使用沙特本地资深供应商 / 项目服务方视角。
- 纯科普默认不带产品，除非用户明确要求或话题天然属于产品转化。
- 产品必须作为行业逻辑或客户处境的自然结论出现，不能硬插广告。
- 口播要像真人对镜头说话，避免宣传册腔、公文腔和模板腔。
- 不编造案例、客户反馈、审批结果、测试报告、法规条款或市场现状。
- 不输出无法证明的绝对承诺，例如“100%安全”“一定通过验收”“完全不会返臭”。
- 涉及公司产品参数、规格、法规、国际热点或市场事实时，必须在底部列出本稿实际用到的资料出处。

## 事实核实重点

以下内容属于高风险事实，不能凭印象写：

- 钢材型号、墙体厚度、玻璃棉厚度、镀锌量、耐火时长
- 抗风、抗震、防腐、使用寿命、质保年限
- 装柜数量、打包尺寸、安装时长、产能、价格
- SBC、Civil Defense、Salamah、SABER/SASO、ZATCA 等合规表述
- 工厂面积、库存、交付能力、项目案例、客户反馈
- 当前国际热点、航运、能源、贸易、竞品和市场现状

如果资料之间出现冲突，优先查看 `knowledge/钧瀚产品优势分级分类总表_v4.xlsx` 中的冲突登记；仍无法判断时，应向用户确认。

## 维护建议

- 新增公司资料时，优先放入 `knowledge/`。
- 新增资料后，同步更新 `knowledge/AI资料导航索引.md`。
- 如果某类脚本反复出问题，优先把规则补进 `AGENTS.md` 或对应 skill，而不是临时改提示词。
- 如果发现某个参数存在多个版本，不要直接覆盖，应在知识库中保留冲突记录并标注待核实。
- 每次调整规则或知识库后，建议提交到 GitHub，便于回溯文案工作流的演进。
